## A simple Autoencoder tutorial

We use autoencoder for its latent space with the main idea that it reduces the dimensionality of the input space and converts it into a less dimension latent space which captures most of the features and the original data can be generated again from the latent space.

We care about the quality of the output data reconstruction (i.e. a good loss) because the quality of the output reconstruction is directly related to the quality of the latent space.
